## Verified P0 failures

The marketplace Stripe webhook:

`POST /api/stripe/marketplace-webhook`

has behaviorally verified defects:

1. Unsigned requests can create financial records.
2. Missing marketplace secret does not fail closed.
3. Missing signature does not fail closed.
4. Valid signed requests cannot reach proper verification because:

   * `getUncachableStripeClient()` is asynchronous but is called without `await`

5. Same Stripe event ID can be replayed serially.
6. Same event ID can be replayed concurrently.
7. Same event ID can be reused with conflicting financial values.

12. Marketplace financial work has no durable failure/retry model.

* unsigned `invoice.paid` → royalty row created
* serial replay → duplicate financial row
* concurrent replay → duplicate financial rows
* Org A installed resource + metadata Org B → Org B financial attribution
* forced DB failure → HTTP 200 with no durable failure record

This pass must eliminate those failure modes.
