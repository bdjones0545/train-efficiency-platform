## 3. Callback state transitions

Define and enforce valid transitions.

At minimum:

* queued → started
* queued → completed
* queued → failed
* started → completed
* started → failed

Reject or safely ignore invalid regressions such as:

* completed → started
* completed → failed
* failed → started

Duplicate completed or failed callbacks with the same callback ID must return success without applying the result twice.
